Colors, number 3

Carbon

Black on white, as plain as a screen allows, with no tint in either.

This page wears it. Switch the theme to see the other side.

The three colors

Ink is the text, and cloud is the page. Milk is a step off cloud, for a surface above it. Each is written in OKLCH, with the same color in hex under it. Press a value to copy it in OKLCH, or hold Shift as you press to copy the hex.

Color Token Light Dark What it is for
Ink --color-ink oklch(17.8% 0 0deg) #111111 oklch(94.6% 0 0deg) #ededed Text, icons, and the solid buttons.
Cloud --color-cloud oklch(98.5% 0 0deg) #fafafa oklch(14.5% 0 0deg) #0a0a0a The page.
Milk --color-milk oklch(100% 0 0deg) #ffffff oklch(19.6% 0 0deg) #151515 Cards, fields, and anything raised above the page.

The shades between them

Every other shade is ink mixed into cloud, so each one leans the way the pair leans, and each follows the theme. The components work them out; the values below are what a screen shows.

Shade Token Ink in it Light Dark What it is for
Soft --color-ink-soft 68% oklch(43.6% 0 0deg) #515151 oklch(69% 0 0deg) #9b9b9b Running text in prose, and the lede.
Faint --color-ink-faint 58% oklch(51.7% 0 0deg) #686868 oklch(61% 0 0deg) #838383 Hints, captions, and the quietest text.
Strong line --color-line-strong 24% oklch(79.1% 0 0deg) #bbbbbb oklch(33.7% 0 0deg) #373737 The edges of fields and outlined buttons.
Line --color-line 12% oklch(88.8% 0 0deg) #dadada oklch(24.1% 0 0deg) #1f1f1f Rules, and the edges of cards and tables.
Wash --color-wash 6% oklch(93.7% 0 0deg) #eaeaea oklch(19.3% 0 0deg) #141414 A tint behind code, and under a row as the pointer passes.

Contrast

Every text shade reaches WCAG AA, 4.5 to 1, against the page and against a raised surface, in both themes. A test holds it there.

Text Light, on cloud Light, on milk Dark, on cloud Dark, on milk
Ink 18.1 18.9 16.9 15.6
Soft 7.6 7.9 7.1 6.6
Faint 5.3 5.6 5.2 4.8

Use it

Take a copy of 3.css, keep it with the site's own styles, outside the components' folder, and link it after them: 

<link rel="stylesheet" href="/ui/ui.css" />
<link rel="stylesheet" href="/styles/carbon.css" />
