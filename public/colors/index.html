Colors

Pairs of colors for the components. Each is three tokens, and every other shade is mixed from them, in light and in dark.

A color has a number, which is its address, and a name, which is only for reading: /colors/01/navy/ and /colors/01/ are the same page. So a color can be renamed, and every link to it still works. The same list is in colors.json, as data. Every text shade in every color reaches 4.5 to 1, in both themes; a test holds them there.

Colors are written in OKLCH: lightness, chroma, and hue, in that order. Two colors with the same hue are the same color at another depth, and it shows in the numbers. The hex under each is the same color, for a tool that wants it.
