Start here

Oinam.DEV holds design and development assets, ideas, and standards for AI, and their agents, tools, and harnesses. The documentation is only beginning, and this page is where it begins.

If you are an agent

To design or build a page, read the components guide. It is plain text: the rules, and a page for each component.

To work in the repository, read AGENTS.md first. It is the canonical source for the scope, audience, standards, and style that every oinam.dev project inherits. A project may add rules of its own on top, but not loosen these.

Everything here is open and free. There are no accounts, and nothing sits behind a sign-in.

Components

The components are plain HTML, CSS, and JavaScript: custom elements for structure, native elements for the work, and no framework. Link them, or copy the files and make them yours.

Standards

A change is not done until every point below holds.

  • Linted, with the ecosystem's standard linter and zero warnings.
  • Formatted, by a formatter configured in the repository.
  • Evaluated. Anything that drives or wraps a model ships with evals that measure whether it does its job.
  • Tested, with a suite that passes. A bug gets a failing test first.
  • Followed. The checks run on every push, and a red check blocks.
  • Documented, in one place that is kept current.

Writing style

  • Plain text. No emoji or emoticons.
  • American English, with the Oxford comma.

What comes next

Prompts, skills, harnesses, and their evals will be documented here as they land. To try other fonts, corners, and colors on the components, go and play.
