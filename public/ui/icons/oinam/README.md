# Oinam's own icons

Icons Oinam draws for itself, where Phosphor has none. There are none yet.

Before drawing one, read "When an icon is missing" in `../../icons.md`: look again, ask Phosphor,
and only then draw it here, on Phosphor's grid, in the four weights Oinam keeps, with the same
file names Phosphor would use (`name.svg`, `name-bold.svg`, `name-fill.svg`,
`name-duotone.svg`).
