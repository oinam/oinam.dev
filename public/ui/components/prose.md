# Prose

A run of writing. Plain headings, paragraphs, and lists get their rhythm.

- Use: `<o-prose>`
- Files: `text.css`. It is CSS alone, and needs no script.
- Part of Oinam UI. The rules for using it are in `../guide.md`.

`<o-prose>` is for a run of writing, such as an article. It gives plain headings, paragraphs, and
lists their spacing, so the HTML inside needs no classes.

```html
<o-prose>
  <h1>Standards</h1>
  <p>A change is not done until every point below holds.</p>
  <h2>Linted</h2>
  <ul>
    <li>Zero warnings.</li>
  </ul>
</o-prose>
```
