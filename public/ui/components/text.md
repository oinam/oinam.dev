# Text

A small label above a heading, and an opening paragraph a size up.

- Use: `.onm-eyebrow, .onm-lede`
- Files: `text.css`. It is CSS alone, and needs no script.
- Part of Oinam UI. The rules for using it are in `../guide.md`.

Headings (`h1` to `h4`) are set in the serif. Paragraphs, links, `<code>`, `<kbd>`, `<pre>`,
`<hr>`, `<strong>`, and `<small>` are styled as they are.

- `class="onm-eyebrow"`: a small label above a heading, such as a date or a section name.
- `class="onm-lede"`: the opening paragraph, a size up.

```html
<p class="onm-eyebrow">Field notes</p>
<h1>A heading</h1>
<p class="onm-lede">The opening paragraph.</p>
```
