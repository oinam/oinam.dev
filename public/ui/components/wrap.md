# Wrap

Centers the page content and keeps it off the edges.

- Use: `<o-wrap>`
- Files: `layout.css`. It is CSS alone, and needs no script.
- Part of Oinam UI. The rules for using it are in `../guide.md`.

`<o-wrap>` centers the page content and keeps it off the edges. 1600px wide at most. Add `narrow`
for a page of reading (56rem).

```html
<o-wrap narrow>
  <p>The content of the page.</p>
</o-wrap>
```
