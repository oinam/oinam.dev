# Empty

Stands where content will be once there is some.

- Use: `<onm-empty>`
- Files: `empty.css`, `button.css`. It is CSS alone, and needs no script.
- Part of Oinam UI. The rules for using it are in `../guide.md`.

`<onm-empty>` stands where content will be once there is some. Say what is missing, and offer the one thing to do about it.

```html
<onm-empty>
  <h3>No bookings yet</h3>
  <p>When a boat books a berth, it shows up here.</p>
  <button class="onm-button" type="button">Book a berth</button>
</onm-empty>
```
