Colors

Pairs of colors for the components. Each is three tokens, and every other shade is mixed from them, in light and in dark.

A color has a number, which is its address, and a name, which is only for reading: /color/01/navy/ and /color/01/ are the same page. So a color can be renamed, and every link to it still works. The same list is in colors.json, as data. Every text shade in every color reaches 4.5 to 1, in both themes; a test holds them there.
