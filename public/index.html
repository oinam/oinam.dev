What is here

Where What it is
/ui/ The components, live: layout, cards, buttons, fields, tabs, and the rest.
/ui/guide.md The components in plain text, for an agent to read: the rules, and a page for each.
/ui/registry.json The components as data, with the files each one needs.
/ui/patterns/ Whole pages built from the components, to follow when composing one.
/ui/why.md What each rule protects, what it costs, and when it may be bent.
/ui/tokens.css Every color, size, and shape. Two colors do all the work.
/play/ Other fonts, corners, and colors, tried on every component at once.
/garden/ One page in many designs, each a few lines of tokens. Add yours.
/colors/ Pairs of colors, side by side in light and dark, each a few tokens.
/docs/ Where the documentation begins, and the standards every project inherits.
/llms.txt A map of this site for language models.
AGENTS.md The instructions for any agent working in the repository.
